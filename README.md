## 🛡️ About Me

I'm a cybersecurity professional and penetration tester. I look for weaknesses in
applications, networks and infrastructure before attackers find them, and I write
clear, actionable reports that help teams fix them.

I also build open-source security tooling. My tools are **passive-first**,
**safe by default** and designed for **authorized, documented** use.

```yaml
name:     Taha Amin
role:     Cybersecurity Professional & Penetration Tester

  - Web Application Penetration Testing
  - Network & Infrastructure Security
  - OSINT & Reconnaissance
  - Security Automation & Tool Development
approach: Scoped, authorized, documented. Every finding comes with a fix.
motto:    "Think like an attacker, act like a defender."
```

## 🔭 What I Work On

- 🌐 **Web application testing:** OWASP Top 10, authentication and session flaws, access control, injection
- 🖧 **Network & infrastructure testing:** enumeration, service exploitation, misconfigurations, privilege escalation
- 🕵️ **OSINT & attack surface mapping:** passive recon, DNS and certificate intelligence, exposure analysis
- 🐍 **Security engineering:** Python tools that automate recon, collection and reporting
- 📝 **Reporting:** risk-rated findings, proof of concept and remediation guidance for technical and non-technical readers

## 🚀 Featured Projects

| Project | What it does | Stack |
| :-- | :-- | :-- |
| 🔎 **[OSINT Tool](https://github.com/TAHAMEO/tool)** | A modular, async, plugin-based OSINT collection and reporting framework. It is passive-first and safe by default, with a policy engine, a hash-chained audit log, per-API rate limiting and robots.txt support. Plugins cover crt.sh, DNS, WHOIS, Shodan, VirusTotal, urlscan, Wayback, GitHub, HTTP headers and HIBP (breach metadata only). It exports JSON, CSV, HTML and interactive graph reports. | Python · FastAPI · SQLite · networkx · Docker |
| 🧅 **[tor-scrape](https://github.com/TAHAMEO/tor-scrape)** | A research-only crawler that reaches public v3 `.onion` sites through Tor and maps how those services link to one another. It stores metadata only, sends only GET requests, respects robots.txt and never bypasses access controls. *Work in progress.* | Python · Tor |
