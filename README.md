### Professional Summary

I am a cybersecurity professional specialising in **penetration testing** and
**offensive security**. I assess web applications, networks and infrastructure
to find exploitable weaknesses, show their real business impact, and give clear,
prioritised remediation guidance.

Alongside client-facing testing, I build **open-source security tooling** in
Python for reconnaissance, OSINT and reporting automation. Every tool I publish
is passive-first, safe by default and designed for authorised, auditable use.

### Featured Projects

#### [OSINT Tool](https://github.com/TAHAMEO/tool)
A modular, asynchronous OSINT collection and reporting framework built around
safety and accountability.
- Policy engine that enforces authorisation and scope before any collection runs
- Tamper-evident, hash-chained audit log of every decision
- Plugins for crt.sh, DNS, WHOIS, Shodan, VirusTotal, urlscan, Wayback, GitHub, HTTP headers and HIBP (breach metadata only)
- Per-API rate limiting, retries with backoff and robots.txt compliance
- JSON, CSV, HTML and interactive graph reports; CLI and optional web API

`Python` `FastAPI` `SQLite` `networkx` `Docker`

#### [tor-scrape](https://github.com/TAHAMEO/tor-scrape)
A research-only crawler that maps how public v3 `.onion` services link to one
another over Tor, for threat intelligence research.
- Stores metadata only, never page content
- GET-only, robots.txt aware, rate-limited per site
- Never bypasses logins, CAPTCHAs or other access controls

`Python` `Tor` &nbsp; *In active development*
